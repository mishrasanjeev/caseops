## Source-Reported Workflow

An authorized design attorney creates an independent restricted design record,
versions a representation set, prepares a jurisdiction-specific application,
records filing, examination, objection, response, hearing, acceptance and
registration, then records publication and a supplied renewal/extension period.
These are source-reported facts, not a finding that an office accepted a filing.
An application has its own registry/jurisdiction identity. Registration needs
its own identifier/date. No trademark class, form or status is substituted.

Revised representations retain exact member document versions, hashes, roles
and locators. Publication requires an explicit instruction; authorization does
not publish the document to any output channel. A variant requires a distinct
root application in the same jurisdiction and a retained source basis. A
cancellation uses a separate proceeding and does not rewrite registration.
Rights claims and successors retain parties, interests, periods and review
evidence separately from the application. No claimed interest is registry title.

## Shared Safety

Every command rechecks current membership/capability, restricted docket access,
parent lifecycle token, workflow version and exact sources under tenant-first
locks. Same-day close/reopen retires stale commands. Terminal parent history is
read-only and requires current access. Revoked or retired sources cannot support
new commands; missing sources do not become successful empty results.
Source/history pages are bounded. Mutation failures retain inputs and evidence.
All document links must remain authorized; any undisclosed-domain link excludes
the document from general AI, portal, export and notification sinks. This version
does not activate any such sink, legal deadline calculator or paid provider.
