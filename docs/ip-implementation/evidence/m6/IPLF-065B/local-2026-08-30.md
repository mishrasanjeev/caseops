## Workflow delivered

Product Guide results, permission-required states, and no-match states expose
independent rating and typed-report controls. Workspace Assistant exposes the
same controls only on assistant-authored turns. A failed submission can retry
with the same idempotency key; a successful replay returns the original record,
while a different payload under the same key fails closed.

The admin queue is bounded to 100 records, filterable by status/surface at the
review surface, and protected by `workspace:admin`. Review uses the record's
current update timestamp as an optimistic-concurrency token. Resolved and
dismissed records are terminal and cannot be silently reopened.

The dated local journey submits a Product Guide rating and typed report,
submits an independent Workspace Assistant rating, opens the admin queue,
moves feedback through review to resolution, verifies all controls at 360px,
and removes its created records through the governed review lifecycle. API
tests independently prove catalog validation, creator privacy, tenant fencing,
surface-specific authorization, redacted audit metadata, bounded loading,
terminal lifecycle, and no underlying answer copy.
