search, explicit active scope, creator-private conversations, exact

60-second deadline and one retry, and rechecks membership, tenant policy,

construction and runtime failures are typed, redacted, and audited. Proposed
draft/task/field actions are descriptive only and cannot write; the task
proposal browser assertion proves the Matter task collection remains empty.
