## Workflow delivered

\`/app/research/reviews\` starts an intelligent review from an existing frozen
saved-research report. The lawyer selects a server-authorized Matter or IP
docket; IP publication additionally requires an existing opposition
proceeding selected from the canonical registry-backed workspace. The browser
does not invent tenant, target, catalog, source, or proceeding identifiers.

The review surface separates supporting and contrary authorities, exact
passages, source URL actions, freshness, contradictions, gaps, and lawyer
checks. The lawyer can include or exclude authorities and add notes before
finalization. Removing support visibly makes the analysis incomplete.
Publishing creates one separately approved Draft and deep-links to the exact
Matter or IP opposition Draft. Docket-only IP analysis may be finalized but
cannot publish an orphan pleading.

Normal, stale/contradictory, inaccessible-source, citation-removal,
Matter-publish, IP-opposition-publish, and 360px paths are encoded in the dated
local and production Playwright specifications. Unit coverage proves that an
explicit proceeding and Draft remain selected after asynchronous query data
arrives, even when neither is first in the returned list.
