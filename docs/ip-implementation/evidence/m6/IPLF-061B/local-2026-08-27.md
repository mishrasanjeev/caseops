## Scope delivered

The existing public `/guide` page now exposes one Product Guide search tool
over the reviewed IPLF-061A catalog. It does not create a second help corpus.
The browser calls the authenticated, bounded `/api/product-guide/search`
contract and renders approved guide results and server-filtered commands.

The workflow covers:

- direct navigation from approved command and guide results;
- missing-capability explanations without restricted destinations or record
  names;
- stale content-version disclosure;
- deterministic abstention and approved suggested searches;
- signed-out, unavailable, validation, retry, loading, and mixed safe-result
  plus denied-command states;
- a stable mobile control layout at 360px.

No schema, migration, backfill, model call, provider call, worker, scheduler,
analytics writer, feedback queue, assistant session, workspace-record
retrieval, or action writer was added.
