## Foundation delivered

Additive migration \`20260828_0001\` generalizes the existing
\`Recommendation\` owner to exactly one tenant-matched Matter or IP docket
target, optionally pins an IP opposition proceeding, freezes the approved
research report and source manifest, and links a separately approved
\`Draft\`. It does not create a duplicate recommendation, source, Matter, IP,
or drafting owner.

The review service bounds source count and passage size, releases the database
transaction before provider work, applies a finite provider deadline, and
reauthorizes tenant membership, target lifecycle, report version, source
access, and output hash before persistence. It fails closed for inaccessible
or unregistered sources, unverified passages, prompt-injection markers,
prohibited predictions, disposed targets, cross-tenant records, and stale
state. Worker claim uses \`FOR UPDATE SKIP LOCKED\`; list work is bounded and
constant-query.

The full schema review found and corrected a missing leading index for the
tenant-scoped \`recommendations.ip_docket_id\` foreign key. Current-head index
health is now asserted by the migration test. A separate tenant-local calendar
helper also removes the UTC-midnight off-by-one defect from IP deadline and
Today calculations.
