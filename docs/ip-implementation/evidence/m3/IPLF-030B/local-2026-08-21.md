## Delivered scope

- Full-scope, cursor-paginated trademark application listing with exact normalized
  application/opposition identifier search; client, proprietor, class, lawyer,
  team, jurisdiction, office, phase, status, deadline, opposition and registry
  freshness filters; scope-wide quality/deadline/freshness counts.
- Correct mark/application/proceeding separation. Application numbers never absorb
  opposition numbers, and proprietor/agent roles are projected independently.
- List and grid views, per-user configurable columns, personal and team saved
  views with optimistic version checks, and narrow-mobile rendering.
- Preview-bound background CSV export with an allow-listed audience-safe column
  contract, formula neutralization, ACL recheck at execution, provenance,
  audited download, failure visibility and retry.
- Controlled UTF-8 CSV/XLSX import (10 MB/1,000-row bounds), typed validation,
  preview expiry/revalidation, error CSV, history, same-file and existing-record
  duplicate suggestions, explicit create/link/skip reconciliation, rotated preview
  tokens, idempotent commit and deterministic crash recovery.
- Import commits delegate to the existing docket, asset, application and identifier
  writers. No second portfolio or registry-number owner was introduced.
- Word, device/logo, composite, label, colour/color, shape, sound and other mark
  categories are retained without coercing document-backed representations to text.
