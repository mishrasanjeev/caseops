## Existing-owner audit

Current `main` was audited before editing. IPLF-024A/024B already own the IP
document schema, taxonomy, naming, immutable versions, object storage,
processing, duplicate detection, typed links, lifecycle transitions and
privilege policy. `IpDocumentWorkspace` already provides the responsive user
workflow on `/app/ip`, and the existing IPLF-024B Playwright file already
crosses the API and browser boundaries.

IPLF-036B therefore adds no table, migration, storage path, document writer,
processing worker, policy engine, route or parallel UI. This slice records
fresh proof and reconciles the remaining planned manifest projections.

## Verified behavior

- Tenant taxonomy seeding and reviewed alias import are isolated by company.
- Original filename and bytes remain immutable while controlled display names
  are previewed, sanitised and conflict-suffixed without silent overwrite.
- Content hash plus metadata identifies duplicates, and one document can link
  to multiple dockets without copying stored content.
- Version lifecycle transitions preserve actor/time evidence and lock approved
  or filed versions.
- OCR quality is recorded; low-quality or privileged content fails closed for
  AI retrieval, portal sharing, export and notification content.
- The browser exposes upload, naming preview, alias import, new-version,
  download, classification preview and lifecycle controls at 360 px without
  horizontal overflow.
