## Implemented boundary

IPLF-038A adds a versioned, internal-only synchronous report-definition and preview adapter for:

- portfolio register;
- deadline control;
- renewal; and
- data quality.

Every preview includes generated time, UTC timezone, normalized filters, audience,
confidentiality, source cutoffs, unavailable sources, row count, truncation state, summary,
and a deterministic SHA-256 snapshot digest. Preview generation writes only the shared
`ip.report.previewed` audit event.

The input contract rejects unknown top-level fields, misspelled nested filters, unsupported
client audiences, invalid renewal states, and row limits above the synchronous ceiling. Access
is authenticated and tenant scoped. Existing record-access predicates omit restricted records
without rows, identifiers, titles, counts, or query-probe confirmation.
