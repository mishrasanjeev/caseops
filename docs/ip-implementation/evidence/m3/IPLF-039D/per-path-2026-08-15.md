## Outcome

The 2026-08-15 audit correctly found that four of six UJ-58 paths were absent.
All six paths are now implemented through one restricted, human-controlled
incident lifecycle. Evidence is content-minimised and retained; CaseOps does
not invent a remedy, deadline or communication; and platform-wide defects
disable affected configured automations until evidenced release after closure.

Release remains blocked because this implementation revision has not yet been
merged, deployed and exercised as a dated production candidate. Historical
production evidence at `b7365cc1` does not prove this change.

## Per-path proof

| Path | Implemented and tested behaviour |
|---|---|
| `UJ-58-NORMAL` | A restricted incident freezes version/source/audit references, requires immutable impact scan results, completed containment/corrective/prevention actions and approved decisions for client, insurer, regulator and court before a human can record a `verified` outcome. Terminal evidence cannot be mutated. |
| `UJ-58-EXC-01` | A suspicion can close as `disproved` only after the impact scan and recipient decisions. The incident, scan and decisions remain accessible and retained. |
| `UJ-58-EXC-02` | Opening, assessing and resolving an incident creates no operational deadline and no notification intent. Every remedy and communication remains an explicit human record. |
| `UJ-58-EXC-03` | Incident deletion consults the canonical legal-hold resolver. An active hold returns a hold-specific conflict; without a hold, records policy still retains the evidence. No delete path silently succeeds. |
| `UJ-58-EXC-04` | Client, insurer, regulator and court decisions are separate append-only versions. Private recipient references are stored as SHA-256 values and never returned in plaintext. |
| `UJ-58-EXC-05` | A platform-wide incident activates one persisted kill switch per selected automated feature, removes those features from the tenant's enabled automation configuration, blocks readiness and re-enable, and permits optimistic, evidenced release only after terminal resolution. |

Additional proof covers restricted cross-tenant non-disclosure, SQLite full
migration history, empty rollback/re-upgrade, PostgreSQL append-only triggers,
tenant-correlated foreign keys and indexes, the complete UI control sequence,
and a real browser journey from bootstrap through verified resolution.
