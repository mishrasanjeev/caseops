# IPLF-031B - manual trademark application and identity workflow

**Slice:** `IPLF-031B` (M3; repository implemented and locally verified, not released)

## Delivered scope

- Added one atomic manual-application command that composes the existing docket,
  asset, application, typed-identifier and trademark-particular writers. Any
  validation failure rolls the complete record back.
- Replaced legacy manual docketing with a complete trademark application form:
  optional matter, restricted access, jurisdiction, office, filing phase,
  source/effective date, application number or explicit pending allocation,
  representation, class specification, applicant and filing evidence.
- Kept application, registration, opposition, rectification, appeal and court
  identifiers visibly separate. An application number is never copied into the
  legacy docket primary identifier.
- Added duplicate-candidate review with explicit separate-filing or supersession
  decisions, required reasons, correction history, and guarded filing-phase
  progression.
- Added a responsive selected-docket identity workspace and updated the in-product
  guide for draft, pending-allocation and duplicate-review behavior.
