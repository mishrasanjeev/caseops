## Implemented boundary

The `iplf-038b-v1` contract exposes nine synchronous internal report previews:
portfolio register, application status, opposition status, deadline control,
renewal, watch, workload, data quality, and integration freshness. Every preview
records generated time, UTC timezone, normalized filters, internal audience,
confidentiality, source cutoffs, unavailable sources, row count/truncation, a
summary, visible rows, and a SHA-256 snapshot identifier.

The implementation delegates to existing access-filtered portfolio,
docket-control, renewal, daily-docket, and connector-health readers. A new
read-only connector-health reader prevents report generation from refreshing or
creating operational health rows. The only report-side write is the shared
`ip.report.previewed` audit event.

The `/app/ip/reports` workspace supports report selection, relevant portfolio
and renewal filters, confidentiality, bounded row limits, freshness warnings,
summary and tabular results, unavailable and empty states, access denial, and
desktop/mobile layouts. The user guide, sidebar, generated OpenAPI types, and
law-firm page are updated to the same boundary.
