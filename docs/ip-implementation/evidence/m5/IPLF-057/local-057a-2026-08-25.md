## Duplicate-work reconciliation

The foundation adds one PRD-named type-specific aggregate,
`trademark_international_registrations`. A row is either the international
registration or one independently docketed designation. It does not add a
parallel event ledger, relationship graph, deadline, cost, document, source,
provider-operation, Matter, access, audit, or lifecycle owner.

| Madrid concern | Canonical owner |
| --- | --- |
| Access and legal lifecycle | `ip_docket_records` and existing IP lifecycle service |
| Basic-mark and designation links | `ip_relationships` |
| WIPO/national sourced facts | Append-only `ip_docket_events` |
| Deadlines, costs, documents and tasks | Existing shared/IP owners from PRD Section 11.2 |
| Registry/provider readiness and replay | IPLF-051/IPLF-056 shared owners |
| Type-specific IR/designation facts | New `trademark_international_registrations` aggregate |

No separate designation table is needed: each designation has its own typed row
and its own docket, while `parent_registration_id` preserves the aggregate.
`wipo_status` and `national_status` are separate fields, and the international
registration cannot store a national status.

## Contract and persistence

- Added tenant-composite foreign keys for docket, parent registration, basic
  application, creator, and updater.
- Added partial uniqueness for one tenant IR number and one designation member/
  effective-date identity.
- Outbound registrations require an active Indian basic application. A
  designation must match its parent direction and cannot own the IR number or
  basic-application link.
- New specialized dockets are created atomically with creator access and audit;
  controlled imports may supply an existing correctly typed docket.
- Reads reuse the canonical IP visibility predicate and suppress disposed,
  archived, inaccessible, cross-tenant, and non-operational Matter-linked rows.
- The migration is additive with a five-second PostgreSQL lock timeout, empty
  rollback proof, and restore-forward refusal once legal records exist.
