## Ownership and duplicate-work review

IPLF-057B extends the IPLF-057A `TrademarkInternationalRegistration`
aggregate and does not add a second legal or operational owner. The existing IP
docket remains the access/lifecycle boundary; `IpDocketEvent` remains the
append-only sourced transaction and reconciliation ledger; existing deadline,
document, cost, relationship, audit, Matter, and provider-operation services
remain canonical.

The additive `20260825_0004` migration repairs a foundation compatibility gap:
Madrid dockets created before this slice had no `IpTrademarkParticularVersion`,
although shared docket/deadline/cost readers require one. New Madrid intake now
creates that projection atomically. The migration performs a bounded backfill,
keeps valid projections on downgrade, and never replaces the Madrid aggregate as
the owner of international facts.

## Implemented workflow

- Added workspace and typed action endpoints with optimistic record and docket
  lifecycle versions.
- Added outbound MM2/form, fee, Office of Origin, irregularity, IR, dependency,
  central-attack, subsequent-designation, change, and renewal transactions.
- Added designation-level examination, provisional refusal, response,
  publication, opposition, grant/refusal statement, and local-agent work.
- WIPO and national-office status snapshots are immutable candidates. Only an
  explicit internal reconciliation decision can apply the authority-owned
  status; one designation cannot update its parent or sibling.
- Central-attack/dependency records are impact-review-only and cannot cancel or
  otherwise mutate legal status.
- The workspace queries a bounded set of linked documents and reuses canonical
  deadlines and cost items. Invented or cross-docket references fail closed.
- Added a responsive Madrid portfolio with intake, family status, source review,
  evidence, history, and all transaction controls. Reconciled event history
  retains openable source URLs.
- Registered `wipo-madrid` in the existing provider catalog/readiness dashboard
  with zero implemented capabilities and explicit contract, licensing,
  credential, legal-coverage, and activation blockers.
- Updated navigation, the user guide, generated API client, and law-firm landing
  page. Public copy states that the shipped workflow is manual sourced evidence,
  not live WIPO sync.
