## Release boundary

The candidate performs no live IP India or Indian Kanoon call and no credential
rotation or destructive connector disconnect. Live provider activation remains
blocked until authorized provider, legal, security and release owners supply and
approve contracts, permitted uses, retention, coverage, cost profiles and secret
references. Repository implementation and synthetic/default-off acceptance can ship
independently; exact candidate CI, merge, deployment and dated production acceptance
remain required before `deployment_verified`.

The Product Guide and law-firm landing page already describe the same shared
provider-operations, source, registry and manual-fallback contracts. They were
reviewed in this slice and deliberately not duplicated or broadened into unsupported
live-provider claims.
