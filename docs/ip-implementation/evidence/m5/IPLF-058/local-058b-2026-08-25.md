## Ownership and duplicate-work review

IPLF-058B exposes and hardens the IPLF-058A recordal aggregate. It does not add
another recordal table, title ledger, registry client, document store, deadline
engine, cost ledger, audit log, permission model, or lifecycle writer.

The effective-dated `IpTitleInterest` ledger and related-right links remain owned
by IPLF-039E. Renewal and restoration remain in the IPLF-037 renewal workspace.
Cancellation, rectification and non-use remain IPLF-049 proceedings. The new
page links to those canonical workflows instead of recreating them.

## Implemented workflow

- Added the `/app/ip/recordals` workspace with type/status filters, direct
  post-registration intake, same-docket instrument selection, parties, legal
  basis, form, dates, affected identifiers/classes, partial scope, cost links,
  and recordal deadline rule references.
- Added capability-aware draft review, filing, acknowledgement, defect,
  correction, re-filing, acceptance, rejection and withdrawal controls.
- A corrected transaction now fails closed at the API unless it has evidence
  and a docket-linked corrected instrument.
- Registry acceptance remains `ip:approve` gated, requires an exact immutable
  confirmed Registry snapshot and records its source URL, reference and date.
  A normalized Registry/instrument party mismatch now additionally requires an
  explicit conflict-review decision and records both detection and approval in
  the append-only event payload.
- Added a dated title view that separately answers Registry-recorded and
  beneficial/effective ownership. Pending/unrecorded interests, partial scope,
  overlap flags, executed-not-effective interests, gaps, inaccessible evidence,
  restricted evidence and related-right cycles remain explicit.
- Added a downloadable date-specific title report and openable Registry/history
  source links.
- Added navigation, user-guide coverage, and a truthful law-firm capability
  claim. The landing copy describes a manual, reviewed workflow and does not
  claim live Registry synchronization.
