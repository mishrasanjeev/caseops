# IPLF-055 local implementation evidence

**Date:** 2026-08-25
**Scope:** Existing client portal extended to IP grants, approved publications, delivery, access invalidation, and structured instructions.

## Ownership and implementation

- Extends `PortalUser`, the physical `matter_portal_grants` owner, portal auth/session, durable `NotificationDeliveryIntent`, IP documents, reports, and `IpClientInstruction`; no second portal, notification queue, document store, or instruction ledger exists.
- A grant targets exactly one Matter or IP docket. IP grants carry tenant correlation, expiry, version, explicit status/identifier/event/date/document/instruction policy, and complete revocation evidence.
- Client report artifacts are immutable, client-safe snapshots approved from a deterministic reviewed fingerprint. Ungranted rows are omitted without a count and sensitive/internal fields are allowlisted out.
- Only approved/filed/served/accepted, non-privileged, internal document versions in a granted taxonomy category and linked docket may be published.
- Publication targets snapshot docket, lifecycle, and access-policy versions. Grant revocation, expiry, lifecycle/archive, or any target version change withholds content and rechecks again before delivery.
- Client instructions are versioned and remain pending until a firm user accepts, rejects, or requests clarification. They do not mutate legal state on submission.
- Revocation invalidates active portal sessions and cancels queued publication delivery. Delivery includes the portal recipient and a firm escalation path.
- Portfolio records and publication dependencies are batch-loaded with fixed query budgets; list size and child rows are capped.

## User surfaces

- `/app/ip/client-portal`: invite/grant, expiry, category scope, active/historical grants, revoke, approved document publication, pending instruction acknowledgement.
- `/app/ip/reports`: reviewed internal preview, client/grant selection, immediate or scheduled publication.
- `/portal`: explicitly granted IP records and approved publication state alongside existing Matters.
- `/portal/ip/[id]`: identifiers/status, selected events/dates, approved reports/documents, and structured instruction submission.
- Sidebar, guide, law-firm page, and generated OpenAPI client types updated.
