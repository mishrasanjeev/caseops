# IPLF-052 / IPLF-053 local implementation evidence - 2026-08-24

## Scope and duplicate-work decision

IPLF-052 owns journal ingestion, watch profiles, candidate hits, source evidence,
review, notifications, and correction lineage. IPLF-053 allocates the same five
`IP-WATCH` requirements and the same UJ-21/UJ-33 paths to the downstream
opposition/enforcement handoff. The implementation is one integrated candidate:
IPLF-053 adds no duplicate task, deadline, Matter, opposition, notification, or
client-report store. It delegates to the existing canonical owners and preserves
the reviewed source snapshot and decision on an append-only handoff record.

## Implemented behavior

- Docket-scoped profiles support word, phonetic, device, Nice class, proprietor,
  and jurisdiction criteria with explicit frequency, recipients, provider, and
  per-period cost ceiling.
- Immutable journal publications retain journal/application identity, published
  mark and scope, official URL/page, attribution, parser version, raw evidence,
  retrieval time, source status, and correction/re-advertisement lineage.
- Ingestion idempotency is payload-bound. Replay returns the exact original
  publication and hit IDs; reuse with a different payload returns `409`.
- Hits expose compared and candidate marks, classes/goods, versioned similarity
  evidence, source/date/provenance, duplicate lineage, stale status, and a
  permanent AI-advisory notice.
- Accessible profile recipients receive durable in-app notification intents.
  Source-dependent final dispositions and all action handoffs require a human
  source confirmation and written reason.
- Relevant hits hand off without re-entry to the canonical opposition,
  enforcement Matter, shared task, operational deadline, or append-only docket
  event used as a client-report evidence item. The canonical target, Matter
  link where applicable, audit record, and immutable handoff evidence commit in
  one caller-owned transaction.
- Correction/re-advertisement review supersedes the prior hit's deadline state
  only after the successor official source is confirmed. Partial scope and
  delayed/stale intake remain visible.
- `caseops-ip-journal-watch` records due checks. Manual profiles make zero
  external calls; unactivated providers pause visibly and fail closed; exhausted
  cost ceilings pause before acquisition.
- `/app/ip/watch`, sidebar navigation, operator guide, law-firm page, OpenAPI
  types, event catalogue, scheduler inventory/deploy manifests, and the repository
  data-governance map are updated.

The first Playwright run correctly failed on the enforcement path because the
new adapter supplied an invalid canonical Matter `forum_level`. The service now
uses `advisory`; a backend regression asserts the Matter contract and the entire
browser journey then passed.

A subsequent transaction audit found that canonical helpers could commit a
target before the immutable watch-handoff link. The helpers now support a
caller-owned transaction while retaining their existing default behavior. A
failure injected at the final handoff audit proves that the Matter, docket link,
handoff, and audit all roll back and that an unchanged retry creates exactly one
target and one handoff.

PR review then identified six release-blocking gaps. The corrected candidate
excludes terminal/archived dockets from scheduler work; caps publications,
profiles, comparisons, and hits; batch-loads publication/profile matching state;
requires affirmative reference-bound device evidence; resets spend at explicit
UTC day/week/month boundaries; rejects cross-currency charging; and uses a
wrapping two-column mobile view selector with browser geometry assertions.

## Release and rollback boundary

- Current state: implemented and locally verified; not merged, deployed, or
  production-verified by this evidence.
- Deploy the additive migration before the new API/web revisions. Old revisions
  remain compatible with the expanded schema.
- If runtime acceptance fails, disable `caseops-ip-journal-watch` and roll API/web
  traffic back to the prior immutable release. Do not downgrade after journal
  evidence exists: the migration deliberately refuses destructive evidence loss.
- Live provider activation remains blocked until contract/licensing, credentials,
  source coverage, cost policy, and provider acceptance exist. No external journal
  provider call is claimed here.
- The repository-owner sign-off waiver is not legal advice, provider acceptance,
  or independent law-firm UAT.
