## Canonical-owner and duplicate analysis

Classification for this slice is `NEW` governance metadata. It does not become
an application-state writer. Application state remains with the exact owner in
the ledger: an existing Section 11.2 owner, a PRD-named new IP legal owner, or a
PRD-named neutral shared foundation.

The guard rejects exact forbidden records such as `ip_tasks`, `ip_hearings`,
`ip_notices`, `ip_access_grants`, `ip_import_jobs`, and
`legal_source_records`. It also normalizes file names and CamelCase source text
to reject disguised IP-private notification, provider operations/readiness,
report/export, or email/OAuth/calendar/Drive connector control planes.
