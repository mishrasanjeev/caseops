## Production discovery and repair

The first entitled-canary release reproduced two HTTP 500 responses after
hearing reschedule. Cloud Run logs identified
`psycopg.errors.UndefinedFunction`: a `SELECT DISTINCT` covered
`UserCalendarConnection.scopes_json`, and PostgreSQL has no equality operator
for `json`. The legal mutation had committed, but calendar resync made the
response fail.

PR #203 replaced the join/`DISTINCT` query with a correlated `EXISTS`
predicate and added a real-PostgreSQL no-provider regression. The final exact
release and unchanged production journey prove the response now succeeds.
This incident did not involve a customer tenant or an external provider
operation.
