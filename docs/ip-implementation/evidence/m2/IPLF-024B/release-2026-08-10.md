## Delivered scope

1. Authenticated users can upload originals and immutable new versions through
   the shared storage, malware, quota, and processing owners.
2. Duplicate detection uses content hash, size, content type, and taxonomy;
   exact duplicate bytes can be reused without retaining a temporary second
   object, while different bytes or taxonomy remain distinct.
3. Documents and versions link to typed docket, application, proceeding,
   event, and deadline targets without duplicating binary storage.
4. Draft, review, approved, filed, served, accepted, rejected, and superseded
   transitions are row-locked and optimistic-concurrency protected. Approval
   and filing record actor/time locks and require the separate approval
   capability.
5. Deterministic naming and bulk classification are preview-token controlled;
   changed input invalidates preview and apply is atomic and no-overwrite.
6. OCR/extraction quality, confidentiality, and privilege policies fail closed
   for AI, portal, export, and notification actions.
7. Taxonomy alias import supports dry-run, idempotent apply, and normalized
   tenant conflict detection.
8. The responsive IP document workspace exposes capability-composed controls
   at 360px with shrinkable, full-width, wrapping grouped actions.
